Project Reflection

During this project, one of the main challenges I encountered was recreating the Frontend Mentor testimonial grid accurately while also making the layout responsive. The desktop design required multiple testimonial cards of different sizes, with Kira’s card extending along the right side. At first, organizing the cards with Bootstrap’s grid system was challenging because I needed to understand how rows, columns, and responsive breakpoints worked together.

I solved this problem by using a nested Bootstrap grid with responsive column classes such as `col-12`, `col-md-*`, and `col-lg-*`. I also used Bootstrap cards, Flexbox utilities, spacing classes, and custom CSS to improve the colors, typography, profile images, shadows, and overall appearance.

If I had more time, I would continue comparing the webpage with the original Figma design and fine-tune the spacing, font sizes, card dimensions, and breakpoints to make the implementation even more pixel-perfect.
