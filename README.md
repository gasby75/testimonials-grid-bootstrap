Testimonials Grid Section - Bootstrap

Overview

This project is my implementation of the Frontend Mentor Testimonials Grid Section challenge. The goal was to recreate the provided design as accurately as possible while using Bootstrap to create a responsive layout.

The project uses HTML, Bootstrap, and custom CSS.

Frontend Mentor Challenge

Testimonials Grid Section

https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7

Approach

I used Bootstrap's grid system to create the main responsive layout. The testimonial cards use Bootstrap classes such as `container`, `row`, `col-*`, `card`, `d-flex`, spacing utilities, and responsive breakpoints.

I also added custom CSS to match the original design more closely, including background colors, typography, profile images, shadows, rounded corners, and the quotation background image on Daniel's testimonial.

Responsive Design

The layout changes depending on the screen size. On larger screens, the testimonial cards are displayed in a multi-column grid. On smaller screens, the cards stack vertically to provide a mobile-friendly layout.

My Challenges

One challenge was reproducing the desktop layout while keeping the page responsive. Kira's testimonial needed to remain on the right side of the desktop layout while the other four testimonials formed two rows.

I addressed this by using a nested Bootstrap grid and responsive column classes.

Another challenge was matching the visual appearance of the Frontend Mentor design. I used custom CSS together with Bootstrap utilities to improve the colors, spacing, typography, profile images, and card styling.
